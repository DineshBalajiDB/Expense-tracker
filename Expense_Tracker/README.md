# Daily Expense Tracker

A simple, responsive web application for tracking daily expenses with localStorage persistence.

## Features

- Add expenses with amount, description, date, and category
- View all expenses in a clean list
- Calculate and display total expenses
- Delete expenses
- Fully responsive design for mobile and desktop
- Data persists in browser localStorage

## Files

- `index.html` - Main HTML structure
- `styles.css` - Styling and responsive design
- `script.js` - Application logic and localStorage management

## Deployment Options

### Option 1: GitHub Pages (Free)

1. Create a new repository on GitHub
2. Upload all files to the repository
3. Go to Settings > Pages
4. Select the main branch as source
5. Your site will be available at `https://yourusername.github.io/repository-name`

### Option 2: Netlify (Free)

1. Create an account at [netlify.com](https://netlify.com)
2. Drag and drop the project folder to Netlify
3. Your site will be live instantly with a custom URL
4. Or connect your GitHub repository for automatic deployments

### Option 3: Vercel (Free)

1. Create an account at [vercel.com](https://vercel.com)
2. Import your project from GitHub or upload files
3. Deploy with one click
4. Get a custom URL instantly

### Option 4: Any Static Hosting

This is a static website, so it can be hosted on any static hosting service:
- GitHub Pages
- Netlify
- Vercel
- Firebase Hosting
- AWS S3 + CloudFront
- Any web server

Simply upload all files to your hosting service.

## Local Development

1. Clone or download this repository
2. Open `index.html` in a web browser
3. No build process or dependencies required!

## Browser Support

Works on all modern browsers that support:
- ES6 JavaScript
- localStorage API
- CSS Grid and Flexbox
